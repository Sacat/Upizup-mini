# Up Iz Up Mini — Definition of Done

## Task complete

A task is complete only when:

- Its acceptance criteria are demonstrated.
- Unity compiles without new project errors.
- Relevant automated tests pass.
- Required scene/runtime checks are performed.
- Exact files and verification results are documented.
- Known limitations are stated honestly.
- Ownership is released.

## Grand Bay Chapter One complete

- A new player can finish the chapter without developer intervention.
- The opening tutorial, farming, selling, progression, heat, police, vehicle, and safehouse loops work together.
- Four to six missions have clear objectives and completion states.
- Save/load restores meaningful progress.
- Windows build receives a complete manual play-through.
- No blocker, placeholder instruction, or broken interaction prevents completion.
- Performance is stable enough to begin the Android pass.
