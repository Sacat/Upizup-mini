## Known construction hazards found during continuation audit

1. Mini168GrandBayExpansionCopy.Build deletes and recreates an existing copy. Once expansion work starts, do not rerun it: it would erase that work. Add an explicit create-once or separate reset operation before building further.
2. The copy shares external materials and meshes with its source. Duplicating a scene is not asset isolation. New or altered meshes/materials must be stored under this district's Staging or Generated directory. Do not edit shared source assets.
3. The validator records a new protected hash baseline during Build. Do not reset that baseline to make a failure pass. Compare the historical baseline and Git diff first.
4. The prior scaffold approval template emitted control characters from PowerShell escape handling. Its generated APPROVALS.md was replaced with clean text. Validate generated documents, not just the manifest schema.
5. Unity-generated scene and meta files contain trailing spaces. The checkpoint passed Unity checks but not a clean whole-scene whitespace check. Do not misreport this as a compiler failure.
